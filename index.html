EasyScript

Prompts, automatización y QA para el flujo de scripting

Repositorio modular · Archivos por ruta

Todos los prompts y scripts del proceso EasyScript organizados por su ruta real.

Consulta, filtra, copia y descarga cada recurso desde su archivo real. El catálogo conserva la estructura de carpetas del repositorio y carga el contenido únicamente cuando se necesita.

Arquitectura prevista

  • ◈ Datos: secciones, categorías y recursos.
  • ◈ Servicios: búsqueda, filtrado y descargas.
  • ◈ Componentes: tarjetas, filtros y visor.
  • ◈ App: coordinación del estado y eventos.
Vista completa
Fuente modular: el catálogo se define en js/repository-config.js y el contenido se carga desde la ruta real de cada archivo. Para visualizarlo correctamente, abre el proyecto mediante un servidor HTTP local.
